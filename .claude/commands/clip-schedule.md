description: Run the GTA 6 clipper automatically every day (Claude Code Desktop, Codex app, or launchd)
argument-hint: [HH:MM]
---

Set up a daily automatic clipping run (run from the clipping-gta-6 project root). The scheduled run executes `/clip-daily` (`.codex/prompts/clip-daily.md` in Codex), which uses saved preferences and never asks questions.

1. Run `python3 -m clipper prefs show` and `python3 -m clipper schedule status`. Ask for any missing choices in one go: time of day (default `schedule_time`), voiceover off/all/agent decides, videos per run, hooks per video, and new uploads per day. Ask with multiple-choice questions: in Claude Code use the AskUserQuestion tool; in Codex use request_user_input if available (Plan mode), otherwise list numbered options and wait for the reply. Save them with `python3 -m clipper prefs set …`. If voiceover isn't off, run `python3 -m clipper voice-setup` so the unattended run has a Fish Audio key.
2. Create the schedule natively in whichever app you are running in:
   - **Claude Code Desktop:** create a *local* scheduled task (Scheduled → New task → Only on this computer, or simply create it yourself if you can schedule from this session). Name `gta6-daily-clips`, folder = this project, daily at the chosen time, instructions `/clip-daily`, model **Sonnet** (good picks and hooks at a fraction of Opus's usage). For the live chunks, a second task every 2 hours with `/clip-daily live`, also on Sonnet, if the user has no Claude Code CLI. Project permissions in `.claude/settings.json` already allow the clipper commands so it won't stall. The app must be open and the Mac awake; suggest turning on "Keep computer awake".
   - **Codex / ChatGPT desktop app:** create a scheduled task for this project (local, not worktree, since `jobs/` and `exports/` live here), daily at the chosen time, prompt: "Follow .codex/prompts/clip-daily.md exactly." It needs network access (YouTube, Fish Audio) and to run `python3`, `ffmpeg` and `open`.
   - **Claude Code CLI only (no Desktop app):** run `python3 -m clipper schedule install --time HH:MM`. It installs a launchd agent that runs `claude -p /clip-daily` with only the clipper commands allowed, logging to `logs/daily.log`. Remove it with `python3 -m clipper schedule remove`.
3. **Live streams.** If `python3 -m clipper live list` shows streams, run `python3 -m clipper schedule live` whichever app you use: an app's scheduled task can't check every few minutes, and a stream that isn't caught when it goes live loses everything said before. It installs two background jobs (launchd on macOS, systemd on Linux): the stream watcher every 5 minutes (starts a recorder when a listed stream goes live on topic; no AI, so it costs nothing), and `claude -p "/clip-daily live"` every 2 hours (`--every N` to change), which only starts when recorded chunks are analyzed and waiting. Without the Claude Code CLI, add `--watch-only` and create a second scheduled task in the app every 2 hours with `/clip-daily live` (Codex: "Follow .codex/prompts/clip-daily.md for live chunks only."). `python3 -m clipper schedule remove` removes all of them. Tell the user the computer must stay awake for recordings.
4. Offer a test run now (run the `/clip-daily` steps once) so they can see what tomorrow's output will look like in `exports/<date>/`.
