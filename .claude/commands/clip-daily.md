Unattended daily clipping run, started by a scheduled task. **Do not ask the user anything**: use saved preferences and decide everything yourself. Run from the clipping-gta-6 project root. Read `research/viral-gta-shorts.md` first.

0. Live chunks first: `python3 -m clipper live jobs` lists recorded GTA 6 live-stream chunks not clipped yet (if `live.yaml` has streams and `python3 -m clipper live watch` is running on a schedule). For each, run `python3 -m clipper analyze <job>`, then do steps 2–4 for it, then `python3 -m clipper live done <job>` (frees the recording's disk space).
1. `python3 -m clipper daily`. It reads `prefs.yaml`, finds the newest unprocessed GTA 6 uploads from `creators.yaml` (`sources_per_day` of them, first `daily_max_minutes` of long streams), downloads and analyzes them, and prints JSON. If `analyzed` is empty, write "No new GTA 6 uploads today" to `exports/<date>/index.md` and stop.
2. Choose how many videos to make: if `videos_per_run` is `auto`, use `videos_to_export` from the JSON (each source's recommended count, from tiered volume jumps, peaks, hype words and most-replayed, capped by `max_videos_per_run`), so longer, livelier sources give more clips. Drop any pick you judge weak. Otherwise use the number. Read each `candidates.md`, view the contact sheets, and check word timings in `transcript.json`. Apply the research rules: cold open on the reaction or setup line, the moment pays off an open question, 9–25s for reactions, standalone.
3. For each source, write `jobs/<id>/picks.json` exactly as `/clip` step 7 describes, keeping the hooks `python3 -m clipper simulate jobs/<id>/picks.json` lists on its `keep` line (`hooks_per_video`, or the data-chosen count when `auto`). Set `clip_type` per moment and follow its row in the research Playbook (hook order, styles, voiceover, length). Every hook must open a loop. Run `python3 -m clipper check jobs/<id>/picks.json` and fix everything it flags before rendering. Voiceover per `voice`: `off` none, `all` every video, `auto` only where the research says it helps. If a facecam is visible, use `python3 -m clipper frame` for a split layout.
4. Render each source with `python3 -m clipper render <id> --picks jobs/<id>/picks.json`. If it exits with code 3 (no Fish Audio key), re-run with `--allow-say` and note in the report that the voiceover used the built-in macOS voice because no Fish key is saved (run `/clip` or `python3 -m clipper voice-setup` once to add one).
5. Spot-check one frame per video with ffmpeg. Then append a short report to `exports/<date>/index.md`: source videos, chosen moments with source links, and anything skipped and why. Your final message is the same short report.
